      Creates and returns a DOM element (document.createElement('div')) with className 'placeholder-card'. Returns the element.

    Function 3 — buildHistoryCard(entry, expanded):
      Creates and returns a DOM element (document.createElement('div')). Sets className to 'history-card' if expanded is falsy, or 'history-card expanded' if expanded is truthy.

      Compute rowCount: if entry.columns exists and entry.columns.length > 0, set rowCount = entry.rows.length, else set rowCount = null.

      Compute badgeHtml: if entry.error is truthy, use '&lt;span class="card-badge error"&gt;Error&lt;/span&gt;'; otherwise use '&lt;span class="card-badge"&gt;' + rowCount + ' row' + (rowCount !== 1 ? 's' : '') + '&lt;/span&gt;'.

      Compute bodyHtml: if entry.error is truthy, use '&lt;div class="error-box"&gt;' + escHtml(entry.error) + '&lt;/div&gt;'; otherwise use renderSqlBox(entry.sql, entry.explanation) + renderTable(entry.columns || [], entry.rows || []).

      Compute ts: call formatTimestamp(entry.created_at).

After the header: a .history-card-body div containing bodyHtml.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API response → innerHTML | History entry fields (question, sql, explanation, error, created_at) originate from user-supplied input stored in SQLite and returned via GET /api/history or POST /api/ask. These fields cross a trust boundary when injected into innerHTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / XSS | buildHistoryCard — entry.question injected into .card-question span | mitigate | escHtml(entry.question) called before injection into innerHTML; ASVS V5.3.3 |
| T-02-02 | Tampering / XSS | buildHistoryCard — entry.error injected into .error-box | mitigate | escHtml(entry.error) called in bodyHtml assembly before injection |
| T-02-03 | Tampering / XSS | buildHistoryCard — timestamp string injected into .card-timestamp | mitigate | escHtml(ts) called on the formatted timestamp string before injection; low actual risk (comes from Date.toLocaleString) but enforced by policy |
| T-02-04 | Tampering / XSS | buildHistoryCard — sql/explanation via renderSqlBox | accept | renderSqlBox() already calls escHtml() internally (line 541 verified); no double-escape |
| T-02-05 | Tampering / XSS | buildPlaceholderCard — question text | mitigate | escHtml(question) called on question param before injection into placeholder card span |
</threat_model>
