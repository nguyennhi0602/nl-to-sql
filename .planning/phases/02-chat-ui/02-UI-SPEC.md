## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding |
| sm | 8px | Collapsed card internal gap (chevron + question text), chip gap |
| md | 16px | Card body internal padding, section padding |
| lg | 24px | Feed gap between cards |
| xl | 32px | Content area padding (existing `1.5rem` ≈ 24px — keep as-is) |
| 2xl | 48px | Empty state vertical padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- **12px (3×base) — collapsed card header vertical padding:** `padding: 12px 16px` on `.history-card-header`. Justification: 12px top + (15px body text × 1.5 line-height ≈ 22.5px rendered) + 12px bottom ≈ 46.5px effective height, which clears the 44px touch-target minimum. Using 8px top/bottom instead yields ≈ 38.5px — below the 44px floor. Using 16px top/bottom yields ≈ 54.5px — acceptable but over-spaced for a collapsed summary row. 12px is the minimum grid-compliant value (multiple of 4) that satisfies the touch-target constraint.
- Collapsed card height: minimum 44px to meet touch-target accessibility baseline (question text + chevron row padded to `12px` top/bottom = ~46.5px effective height — see exception above).
- Card body padding when expanded: `1rem` (16px) all sides, matching existing `.sql-box`, `.explanation`, `.table-wrap` inner rhythm.
- Chevron toggle button: 24px × 24px clickable area minimum, achieved via `padding: 4px`.

Source: existing index.html CSS (`.input-section` at `1.25rem`, `.sql-box-header` at `0.6rem 1rem`) — new card spacing mirrors these values.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 15px (0.95rem) | 400 regular | 1.5 | Question text in cards, table cells |
| Label | 14px (0.88rem) | 400 regular | 1.5 | Explanation text, error-box text, timestamp |
| Small label | 12px (0.75rem) | 600 semibold | 1.2 | Badge text (row-count, Error, Generating SQL…), SQL box header "Generated SQL", section labels |
| Code | 14px (0.88rem) | 400 regular | 1.4 | SQL pre block (monospace family) |

Weights used: **400 regular** and **600 semibold** — exactly two.

Note on 15px (Body) vs. 14px (Label): these sizes are intentionally close. They do not form a size hierarchy — they distinguish semantic roles. 15px marks the user's question (primary content); 14px marks supporting metadata (explanation text, timestamps, error messages). The distinction is deliberate and role-based, not hierarchical.

Source: index.html existing values (`0.95rem` textarea, `0.88rem` pre/explanation, `0.75rem` table headers/badges). No new sizes introduced.

## Component Inventory

### New Components (CSS classes to add)

#### `.history-feed`
Container div replacing `#results` default empty state. `display: flex; flex-direction: column; gap: 24px`. Holds `.history-card` children.

#### `.history-card`
Card wrapper. `background: #1a1f2e; border: 1px solid #2d3748; border-radius: 12px; overflow: hidden`.
State modifier: `.history-card.expanded` — body becomes visible.

#### `.history-card-header`
Collapsed-view row. `display: flex; align-items: center; gap: 8px; padding: 12px 16px; cursor: pointer; user-select: none; min-height: 44px`.
Contains: chevron icon (left), question text (flex: 1), timestamp, badge (row-count OR "Error").
Accessibility: set `aria-expanded="false"` on the header element; toggle to `aria-expanded="true"` when `.history-card.expanded` is active.

Note: `padding: 12px 16px` uses 12px as a declared spacing exception (see Spacing Scale — Exceptions). This is the minimum grid-compliant vertical padding that keeps the collapsed header above the 44px touch-target floor at 15px body text × 1.5 line-height.

#### `.card-chevron`
Inline SVG `▶` (right-pointing). Rotates to `▼` (90deg) when parent `.history-card.expanded`. CSS: `transition: transform 0.15s; flex-shrink: 0; color: #718096`. Width/height: 14px × 14px. Rotation class: `.history-card.expanded .card-chevron { transform: rotate(90deg) }`.

Placement: **left** of the question text. Mirrors the `.table-card-header` pattern in the sidebar.

Accessibility: add `aria-label="Toggle result"` to the `.history-card-header` element (not the chevron SVG itself, since the entire header is the interactive target). The chevron SVG should carry `aria-hidden="true"`.

#### `.card-question`
Question text span. `flex: 1; font-size: 0.95rem; color: #e2e8f0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap`. On mobile/narrow: allow wrap instead.

#### `.card-timestamp`
Timestamp span. `font-size: 0.75rem; color: #718096; white-space: nowrap; flex-shrink: 0`.
Format: `"May 21, 2026 14:32"` via `new Date(created_at).toLocaleString('en-US', { year: 'numeric', month: 'long', day: 'numeric', hour: '2-digit', minute: '2-digit', hour12: false })`.

#### `.card-badge`
Reuses `.row-count` base style: `background: #0f1117; border: 1px solid #2d3748; border-radius: 12px; padding: 4px 8px; font-size: 0.75rem; font-weight: 600; white-space: nowrap`.
Variant `.card-badge.error`: `border-color: #fc8181; color: #fc8181`. Text: `"Error"`.
Default (success): `color: #a78bfa`. Text: `"N rows"` (same format as existing `.row-count`).

#### `.history-card-body`
Expanded content area. `display: none; padding: 16px; display: flex; flex-direction: column; gap: 16px; border-top: 1px solid #2d3748`.
When `.history-card.expanded`: `display: flex`.
Contains (in order): `.sql-box` (reused), `.explanation` (reused), `.table-wrap` (reused) OR `.error-box` (reused).

#### `.placeholder-card`
In-flight card variant. Same base as `.history-card` but not expandable. Shows: `card-chevron` (hidden/invisible), question text, spinner + `"Generating SQL…"` label on the right side.
`background: #1a1f2e; border: 1px solid #2d3748; border-radius: 12px; padding: 12px 16px; display: flex; align-items: center; gap: 8px`.
Spinner: reuse `.spinner` class (existing 18px × 18px border-spin). Label: `"Generating SQL…"` at `font-size: 0.75rem; color: #718096`.

#### `.clear-history-btn`
Positioned: between `.input-section` and the history feed. `display: block; margin-bottom: 8px; background: transparent; border: 1px solid #fc8181; border-radius: 8px; color: #fc8181; font-size: 0.85rem; font-weight: 600; padding: 8px 16px; cursor: pointer; transition: opacity 0.15s; align-self: flex-start`.
Hover: `opacity: 0.8`.
Hidden when feed is empty (`display: none` when no cards present).

Source: CONTEXT.md D-02, D-03, D-04, D-05, D-08, D-09; index.html existing `.row-count`, `.spinner`, `.table-card-header` pattern.

## Interaction Contract

### Visual Focal Point
After each query completes, the visual focal point is the auto-expanded newest card. It is scrolled into view via `newCard.scrollIntoView({ behavior: 'smooth' })` and rendered with `.expanded` class applied, drawing the user's eye to the latest result.

### Page Load Sequence
1. Call `GET /api/history`. Show nothing in feed until response.
2. Reverse returned array (API returns `id DESC`; display oldest-first).
3. Render each entry as a collapsed `.history-card` (no auto-expand).
4. Show `.clear-history-btn` if `history.length > 0`.
5. After all cards rendered: `lastCard.scrollIntoView({ behavior: 'smooth' })`.
6. If history array is empty: show the existing `.empty-state` div as-is.

Source: CONTEXT.md D-06, D-07.

### Submit New Query
1. Disable `#askBtn`, set text to `<span class="spinner"></span> Asking…` (existing pattern).
2. Append a `.placeholder-card` to the feed (question text + spinner + `"Generating SQL…"`).
3. Show `.clear-history-btn` if it was hidden.
4. `placeholderCard.scrollIntoView({ behavior: 'smooth' })`.
5. On response success: replace placeholder with a real `.history-card`, auto-expand it (add `.expanded` class), `newCard.scrollIntoView({ behavior: 'smooth' })`.
6. On response error: replace placeholder with error `.history-card` (`.card-badge.error` + `.error-box` in body), auto-expand it, scroll to it.
7. Re-enable `#askBtn`, restore text to `"Query"`.

Source: CONTEXT.md D-08, D-04, index.html existing `ask()` pattern.

### Card Toggle
Click anywhere on `.history-card-header` toggles `.expanded` class on the parent `.history-card`. Update `aria-expanded` attribute on `.history-card-header` in sync with the class toggle. Chevron rotates 90deg via CSS transition.

Source: CONTEXT.md D-03; mirrors existing `.table-card` toggle pattern.

### Copy SQL
Reuse existing `copyText(sql, btn)`. Button text: `"Copy"` → `"Copied!"` for 1500ms. Button class: `.copy-btn` (reused). Placed in `.sql-box-header` inside `.history-card-body`.

Source: index.html existing `copyText()`, CONTEXT.md (reusable assets).

### Clear History
1. User clicks `.clear-history-btn`.
2. Call `window.confirm('Clear all history?')` — native browser dialog.
3. If confirmed: call `DELETE /api/history`, clear `#results` innerHTML, replace with `.empty-state`, hide `.clear-history-btn`.
4. If cancelled: no action.

Source: CONTEXT.md D-09.

### Keyboard
Existing `Ctrl+Enter` / `Cmd+Enter` shortcut on textarea triggers `ask()` — no change.

## States Matrix

| State | Collapsed Card Shows | Expanded Card Shows |
|-------|---------------------|---------------------|
| Success (rows > 0) | chevron + question + timestamp + row-count badge | SQL box + Copy SQL + explanation + results table |
| Success (0 rows) | chevron + question + timestamp + `0 rows` badge | SQL box + Copy SQL + explanation + "Query executed — no rows returned." |
